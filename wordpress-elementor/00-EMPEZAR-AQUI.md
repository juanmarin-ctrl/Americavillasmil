# AV Studio Academy → WordPress + Elementor

Paquete listo para montar en **Hostinger** (`abstudioacademy.com`) de forma **autoeditable** con Elementor (sin que el cliente toque código).

## Resumen del camino (30–90 min según práctica)

1. Entrar a **Hostinger** → instalar / abrir WordPress en `abstudioacademy.com`
2. Instalar tema **Hello Elementor** + plugins de la checklist
3. Instalar **Elementor** (+ **Elementor Pro** si tienen licencia TEDUCAS: Header/Footer Theme Builder)
4. Subir `media/` a la Biblioteca de medios
5. Configurar **Site Settings** (colores + tipografías) con `03-ESTILOS-GLOBALES.md`
6. Pegar CSS de `css/elementor-custom.css`
7. Crear Header / Footer en Theme Builder
8. Crear las 11 páginas y armarlas sección a sección con el mockup abierto
9. Configurar menú, formulario, SMTP y legales
10. Entregar al cliente: “editar con Elementor” (lápiz rosa)

---

## Principio clave (para que NO quede bajo código)

- Todo texto = widget **Título** o **Editor de texto**
- Toda imagen = widget **Imagen** (reemplazable desde Medios)
- Botones = widget **Botón** con estilos globales
- Header/Footer = **Theme Builder** (no hardcode)
- Blog = entradas nativas de WordPress
- Cursos = páginas o CPT + plantillas Elementor duplicables
- Animaciones = **Motion Effects** de Elementor (preferible) + CSS suave opcional

El mockup HTML (`../mockup-web/`) es la **referencia visual**. En WordPress se **recrea**, no se embebe el HTML completo.
