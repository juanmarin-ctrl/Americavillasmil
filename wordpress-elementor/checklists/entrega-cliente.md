# Checklist — Entrega al cliente (autoeditable)

## Capacitación mínima (15–20 min)
- [ ] Cómo entrar a WP Admin
- [ ] Editar con Elementor (lápiz / botón rosa)
- [ ] Cambiar un título
- [ ] Cambiar una imagen desde Medios
- [ ] Publicar / Actualizar
- [ ] Crear una entrada de Blog
- [ ] Duplicar una card de curso

## Lo que el cliente NO debe tocar
- Plugins / Temas (salvo acuerdo)
- Custom CSS
- Ajustes de enlaces permanentes
- Usuarios administradores ajenos

## Credenciales a entregar (canal seguro)
- [ ] URL WP Admin
- [ ] Usuario Editor o Admin limitado
- [ ] Correo contacto@abstudioacademy.com (webmail)
- [ ] Enlace al mockup de referencia (opcional)

## Frase para el cliente
> “Para cambiar textos o fotos: Páginas → Editar con Elementor → clic en el elemento → Actualizar. No hace falta código.”
